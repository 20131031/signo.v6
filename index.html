Gemini API 키 설정

GitHub Pages 등 외부 호스팅 환경에서 시그노(SIGNO)를 사용하려면 Google AI Studio에서 발급받은 무료 Gemini API 키가 필요합니다. 입력한 키는 서버에 전송되지 않고 현재 브라우저(LocalStorage)에만 안전하게 저장됩니다.
